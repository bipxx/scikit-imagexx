# Hough line peaks

The candidate accepts plain aligned C-order 2D `uint64` accumulators up to 1,024 rows, 512 angles and fewer than 262,144 cells, with votes up to 1,048,576. Angle and distance vectors are aligned finite C-order `float64` arrays of matching lengths. The distance radius and angle radius after clamping are nonnegative integers up to 32. Threshold defaults to half the maximum and finite nonnegative plain thresholds are supported. The ordinary cap is a nonnegative Python integer or positive infinity. Other inputs use compatibility. The binding verifies owner storage, and the caller keeps inputs stable during the call.

Native code applies separable maxima with constant-zero padding, labels the strict-threshold maxima with full 2D connectivity, and sorts components by maximum vote and reverse row-major label. Each coordinate is the unweighted centroid rounded to nearest even. Suppression reads the filtered value at that coordinate, omits distance row zero from the neighborhood, and reflects distance as `rows - row` when an angle index wraps. The existing shared label primitive stays on its serial worker path within the cell bound and can use its established SIMD dispatch.

NumPy gathers coordinates and supplies default `argsort` when the cap truncates. Stock selections differ across the retained NumPy versions in the two capped tie rows. Empty detection yields three owning `float64` arrays. A cap of zero after detection yields an owning empty `uint64` intensity array and two empty `float64` coordinates.

The [frozen reference](hough-line-peaks-reference-v1.json) captures all 25 rows plus the two profile-specific outcomes.
