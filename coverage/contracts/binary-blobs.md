# Synthetic binary blobs

The public signature is `binary_blobs(length=512, blob_size_fraction=0.1, n_dim=2, volume_fraction=0.5, rng=None, *, boundary_mode='nearest')`. The directly implemented path admits Python integer length from 1 through 2,048 and rank 1 to 3. Its array size and number of sampled points are each capped at 4,194,304. The plain numeric blob fraction is in (0, 1] and produces a blob size of at least 0.1 pixels. The plain numeric volume fraction is in [0, 1]. Plain boundary strings `nearest` and `wrap` are supported. Random input accepts `None`, a nonnegative Python integer, or a NumPy `Generator`.

NumPy owns RNG construction and consumption. The generator draws one rectangular array with the same shape, precision, ordering and coordinate conversion as the original. NumPy scatters the seed coordinates into a C-order float64 field. Repeated coordinates set the same location to one. The existing Gaussian kernel smooths the field in native code. NumPy computes its one-dimensional Gaussian coefficients through the existing filter wrapper. The existing contrast kernel selects and interpolates the linear percentile in native code. The percentile parameter retains upstream's rounding before conversion to a virtual rank. NumPy applies the inclusive cutoff and allocates the Boolean output. A volume fraction of zero can retain maxima, including equal maxima. A zero Gaussian kernel radius can leave tied zeros, which follow the same cutoff.

Inputs outside those bounds, the warning-producing clamp, unconventional numeric objects, and additional RNG inputs use the existing compatibility policy. Routing occurs before any generator draws. The installed kernel SDK dependencies are `gaussian_nd_into` and `contrast_percentiles`. No separate C++ blob generator or RNG implementation is introduced. Runtime SIMD and worker behavior are inherited from those kernels.

The [frozen original record](binary-blobs-reference-v1.json) includes seeded one-, two-, and three-dimensional arrays, exact Gaussian input and output bytes, RNG state transitions, percentile ties, defaults, both boundaries, and representative compatibility errors. The [public probe](../../tests/test_binary_blobs_public.py) checks the native kernel entry points and frozen results. [Benchmark recipes](../../benchmarks/binary_blobs.py) use eight seeded allocation-inclusive public calls with one worker.
