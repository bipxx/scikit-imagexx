# Hough line

The serial candidate accepts ordinary C-order two-dimensional NumPy Boolean and `uint8` masks, default angles, and ordinary contiguous aligned native one-dimensional `float64` angles. Supported extents are 1–4,096 per image axis, up to 1,048,576 pixels, 1–1,024 angles and up to 134,217,728 pixel-angle pairs. Native storage must have a bounded ndarray or immutable bytes owner. The caller must keep inputs stable during the call. The current implementation has one native worker and no separate SIMD entry point.

Every nonzero byte votes once. The output is an owning C-order `uint64` accumulator indexed by signed distance then angle. The distance grid is `[-ceil(sqrt(height² + width²)), ceil(sqrt(height² + width²))]`, with unit spacing. The image and explicit theta stay unchanged, and the function returns the original explicit theta object. NumPy supplies default angles, `cos`, `sin`, and the distance grid. The separate products, addition, signed half adjustment and truncation follow the pinned original Cython vote. Compiling `src/hough_line.cpp` requires `/fp:strict` with MSVC, or no contraction and no fast math with GNU/Clang (`-ffp-contract=off -fno-fast-math -frounding-math`). Both the binding and SDK require round-to-nearest. [Pinned upstream Hough loop](https://github.com/scikit-image/scikit-image/blob/v0.26.0/src/skimage/transform/_hough_transform.pyx#L228) · [Pinned rounding helper](https://github.com/scikit-image/scikit-image/blob/v0.26.0/src/skimage/_shared/interpolation.pxd#L22)

Ordinary Fortran/strided images, signed non-binary numeric images, empty extents and finite reversed theta go through the existing fallback policy. Nonfinite `float64` theta, non-native-endian one-dimensional `float64` theta, and potentially overriding theta subclasses are outside the supported contract and blocked before the unchecked upstream vote. The nonfinite rejection also covers empty foreground, for which compatibility remains unqualified. Arbitrary custom dtypes and exotic owner chains are outside the bounded contract.

[Frozen original reference](hough-line-reference-v1.json) projects 19 contract/control rows and four untimed public endpoints shared by the pinned Windows and minimum Linux profiles. [Public parity and dispatch tests](../../tests/test_hough_line_public.py) and [installed SDK client](../../tests/cmake_consumer/hough_line_consumer.cpp) require explicit integration wiring. The SDK client covers near-half rounding, finite coefficient bounds, output extent and rejection of overlap before writes.

[Fixed benchmark adapter](../../benchmarks/hough_line.py) provides the blank default, linework default, sparse custom and dense custom inputs. The installed comparison includes provider work and output allocation and verifies each candidate output against the current original and the frozen endpoint before sampling. Use the existing sustained one-worker sampler with 250 ms warmup per side and seven accepted samples of at least 100 ms per side. All four cases require parity or better. Candidate builds, native and public parity, installed SDK, performance and release qualification are pending.
