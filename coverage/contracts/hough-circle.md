# Hough circle

The private implementation accepts ordinary Boolean or `uint8` C-order 2D images with nonempty extents through 512 and 1–16 nonnegative integer radii through 64. The accumulator is limited to 4,194,304 cells and the work bound is 67,108,864 possible Bresenham visits. Each nonzero byte casts the same votes. Input arrays and controls outside this domain go through scoped compatibility, including the frozen signed, strided, floating-radius, negative-radius, and empty cases. Native inputs must have a checked owner and stay stable until return.

Planes preserve the supplied radius order and duplicates. Full output pads each spatial side by the maximum radius and unpadded output clips each vote to the image. Stock and candidate return an owning C-order `float64` array. The existing exact Bresenham perimeter primitive preserves duplicate visits, including eight at radius zero. Normalized voting performs a separate binary64 addition of `1 / count` at every visit. Round-to-nearest and no fast-math reassociation are required. Replacing repeated addition with one vote-count division changes the frozen dense result.
