# Progressive probabilistic Hough line

The bounded public route accepts ordinary C-contiguous Boolean and uint8 masks with each extent from 1 to 256 and up to 4,096 nonzero sites. Explicit theta can have from 0 to 256 ordinary aligned contiguous native float64 values. Threshold is 1 to 4,096, and line length and gap are 0 to 256. Seed inputs are plain integers from 0 to 2⁶⁴−1 or ordinary NumPy Generators backed by PCG64. Other layouts, seedless calls, non-PCG64 generators and larger domains use the existing compatibility route. Nonfinite float64 theta is explicitly rejected because the original compiled scatter can use an invalid bin index.

NumPy computes default angles, trig, RNG construction and the single in-place index shuffle. The search visits that permutation in reverse and keeps the first theta column on equal new votes. Each direction follows the fixed-point line with a half-unit start and an inclusive allowed gap. Accepted pairs retain the original endpoint direction and detection order. The signed accumulator subtracts votes at every marked pixel removed during the two passes, including sites that were still waiting to vote. Input masks and angles remain unchanged. The public wrapper produces a fresh list of pairs of endpoint tuples with built-in integer coordinates.

The serial C++ SDK accepts caller-owned complete buffers for the mask, trigonometric coefficients and permutation, and returns an owning vector. The implementation requires round-to-nearest and a build without contraction. The standalone SDK covers span/parameter-bound validation and does not depend on the NumPy provider.

Eighteen matching original observations on the retained Windows and WSL minimum profiles cover four fixed speed cases, first-angle ties, inclusive coordinate length, the gap/deletion distinction, strict and compatibility domains, and passed PCG64 state including its uint32 cache. Keep angle-grid creation, the seed/shuffle, native or original line search and output conversion inside each future one-worker public comparison. Genuine installed native ownership, SDK linkage, per-case speed and release qualification require independent checks.
