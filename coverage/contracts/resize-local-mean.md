# Bounded local mean resize

The bounded route accepts ordinary aligned native C-ordered uint8 and uint16 planes with both extents from 16 to 2,048, grid-intersection mode, and no channel axis. Both output dimensions shrink by complete factors of 2, 4, or 8 for preserved-range input. Normalized resize admits only 2 × 2 factors. The existing compatibility route handles other layouts, dtypes, modes, shapes, and errors. Native outputs are independent writeable C-order float64 views with same-shape owning bases.

The stock weights for complete dyadic blocks are exact. For preserved range every weighted integer term and sum fits exactly in binary64, so the existing native block reducer can produce the same raw mean. For normalized 2 × 2, stock first multiplies each input by the binary64 reciprocal of the dtype maximum. Each of the next two separable reductions has exactly two nonnegative nonzero-eligible terms with weights 1/2. Weight multiplication is exact, zeros cannot change those terms, and each addition has a single rounded result. Native code performs the row reduction followed by the column reduction in that order. Both modes require round-to-nearest.

The observed 8 × 4 and 8 × 8 normalized mismatches are preserved as compatibility cases. The four original benchmark recipes stay frozen. The largest normalized recipe remains outside native coverage and cannot count toward native speed admission. Shared ownership, installed SDK linkage, one-worker measurements, and release qualification remain pending.
