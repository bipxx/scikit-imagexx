# Hysteresis row-span trial

This trial is preserved for review and is **not retained on main**. The new serial 2-D traversal floods horizontal runs, while the existing multi-worker component path is unchanged. Local Windows scoped SIMD/scalar checks each pass 6,308 cases, minimum-NumPy checks each pass 2,164, and normal/dynamic/portable/ASan+UBSan native checks pass 2/2 each. The exhaustive test covers every pair of six-pixel weak/strong masks in four shapes, including label-zero selection. Full CI is pending.

[Paired Linux/Windows run](https://github.com/bipxx/scikit-imagexx/actions/runs/39797056275) measured source `441df0e`, product SHA256 `0e44e440e7b026304fc2bfe77369a0c07bcd0d4c00bdcf5627c1b6dab62003e9`, against scikit-image 0.26.0 and the exact initial native package `fa6a453`. That initial package predates the legacy-NumPy promotion correction; both packages run NumPy 2.5.4 here and pass every corpus case exactly, with fallback disabled. Both OS artifacts contain exact current and baseline packages, wheels, source fingerprints and binary hashes.

The fixed 32-case corpus uses one and four workers, seven randomized samples, seed 1934, size 512, one reference thread, and includes allocation/conversion/dispatch. All 128 rows and raw timing samples are retained below and in JSON.

One-worker geometric means versus the exact native baseline improve **1.026x Linux / 1.075x Windows**; versus upstream they are **1.878x / 1.751x**. Snake masks improve, but float32 equal-threshold controls regress to **0.769x / 0.830x** baseline/current. Linux all-weak/checkerboard controls also regress. These unchanged-dispatch-path regressions must be addressed before retaining the candidate. The next experiment will isolate the traversal in an out-of-line helper; its benefit is not yet measured.
