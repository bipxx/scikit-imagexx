# Sparse-correlation initial experiments

These source-specific experiments are preserved before the new port is merged. Source `b707c0c` has correct timed finite outputs but failed wider dtype-metadata and legacy signaling-scalar tests. `9ea3c8a` corrects those behaviors; its dedicated tests pass 3,532 cases on modern and minimum NumPy. A later candidate integrates the retained hysteresis helper, removes full-row padding maps, reuses tile addresses and reduces wrapper overhead. Its exact-source paired performance is pending. These initial numbers must not be attributed to that later fingerprint.

Both experiments use the same 45-case corpus at one/four workers: six border modes, Fortran/strided layouts, dense/wide/zero/identity/tiny kernels, 1-D and 3-D inputs, and uint8/float32/float64 images. Each OS has 90 rows, seven randomized samples, one reference thread, seed 7213 and size 512. Allocation, promotion, padding and Python dispatch are included. Every timed result passes exact parity against scikit-image 0.26.0 with fallback disabled. Exact wheels, packages and binary/source manifests are preserved in the linked run artifacts.

Initial one-worker geometric means are **1.775x Linux / 2.202x Windows** upstream/native. Casting-correction means are **1.640x / 2.280x**. These are independent runner measurements, not paired native speedups. Linux long 1-D cases remain slower (initial float32 0.642x, uint8 0.828x and float64 0.899x), motivating removal of the full-width padding map. Every slower case and raw sample is retained below.
