# Color distance and route performance

Native dispatch versus original scikit-image, with parity checked before warmed, allocation-inclusive timing. Reference pools use one thread. Raw Lab integer values are not intensity-normalized. All four Lab metrics include mixed dtypes, broadcast/strided/planar inputs, extra channels, scalar pairs and non-default weights. RGB intermediate allocations are included in composed routes. Float32 CIEDE2000 uses its documented hue-roundoff budget; CMC scalar promotion retains the input computation precision budget. The JSON records output and computation dtypes. Ill-conditioned HSV routes check each stage and a propagated ratio error bound. RGB identity rows perform no image processing and are excluded from processing speedup counts.
